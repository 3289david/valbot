# Valorant Hub

Discord bot and website for VALORANT community servers. English and Korean.

- `bot/` - Discord bot (discord.js). See `bot/README.md`.
- `website/` - website, dashboard, player pages and docs (Express). See `website/README.md`.

Both share one data folder (`website/data`). Deploy on Ubuntu: install the website first (`website/deploy/install.sh`), then the bot (`bot/deploy/install.sh`).
